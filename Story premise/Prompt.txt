You are working on an existing Java 2D RPG project called **Echoes of Alderfall**.

Your task is to implement the new main story questline into the existing quest system.

Important: do not rewrite the whole game. First inspect the existing project structure, quest classes, NPC system, objective system, dialogue system, map/location data, item system, enemy/boss system, and save/progress system. Reuse existing patterns wherever possible.

The current quest system supports these objective types:

* defeat
* gather
* visit / inspect

The game already contains the setting of Alderfall, with five kingdoms and several existing cities, towns, villages, caves, ruins, camps, and crypts.

The main story should be called:

**The Twelve Socket Stones**

The player has survived the Demon Queen’s “mercy” and must rebuild trust across Alderfall, gather proof of the Demon Queen’s return, collect twelve socket stones, activate an ancient portal, and eventually confront the Demon Queen.

All main story NPCs must have a **red exclamation mark** above their heads instead of the normal quest marker.

Implement this in a clean, data-driven way if the existing architecture allows it. Avoid hardcoding unless the current project is already hardcoded.

Main goals:

1. Add / update main story quests.
2. Add required main story NPCs.
3. Add twelve socket stone items.
4. Add conditional story item drops.
5. Add boss encounters where supported by the existing enemy system.
6. Add portal activation flow.
7. Add Oathstead Camp progression hooks if the existing settlement system supports them.

* Normal side quests can keep the current marker.
* Main story NPCs should show a red exclamation mark.
* If the NPC has an active main story quest available, show red `!`.
