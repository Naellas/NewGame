Expand the companion questlines so that each companion NPC has a longer personal arc of **7–8 quests**, not only 3–4.

Each companion should feel like they have a full relationship/trust arc before becoming fully loyal to the player. The player should gradually learn their backstory, help them resolve a personal conflict, and then unlock their loyalty / recruitment / upgraded companion state.

Use only the existing objective types where possible:

* defeat
* gather
* visit / inspect

Avoid adding complex mechanics unless the existing engine already supports them.

Each companion questline should follow this structure:

1. **First Contact Quest**
   Introduces the NPC and their local problem.

2. **Practical Help Quest**
   The player helps with something grounded: supplies, roads, medicine, ledgers, tools, bells, crates, etc.

3. **Investigation Quest**
   The player inspects objects that reveal the NPC’s deeper personal issue.

4. **Conflict Quest**
   The player fights enemies connected to the NPC’s past.

5. **Backstory Reveal Quest**
   The NPC admits something personal: guilt, debt, failure, doubt, betrayal, exile, or shame.

6. **Personal Trial Quest**
   The player helps them face the core of their problem.

7. **Loyalty Quest**
   A larger final quest involving a boss, dangerous site, or major decision.

8. **Aftermath Quest / Recruitment Quest**
   The NPC joins fully, unlocks upgraded dialogue, and comments on Oathstead or the main story.

If the current companion system supports recruitment earlier, use the 8th quest as a **loyalty upgrade** instead of first recruitment.

Each quest should include:

* Quest name
* Quest giver
* Location
* Objective type
* Objectives
* Story context
* Quest start dialogue
* Completion dialogue
* Reward or unlock
* Optional implementation notes
