# Grand regional landmarks

Four original RGBA sprites generated with the built-in imagegen tool: Briarbridge
Charter Hall, Ironvale Forge Keep, Embermarket Sun Court and Moonspire Botanical
Glasshouse. Exact prompts and original output paths are in generation.json.
Original PNGs are preserved byte-for-byte, with genuine alpha verified. No raster
postprocessing was applied. Runtime paths and SHA-256 checksums are in manifest.json.

Import from repository root:

powershell -NoProfile -ExecutionPolicy Bypass -File art-source/towns/2026-09-23-town-architecture/import.ps1 -BatchDirectory art-source/towns/2026-09-24-grand-landmarks

Review: cardinal-facing silhouettes inspected by agent; in-game review inspected; user acceptance pending.
Existing smaller originals remain available. Foxbarrow uses the old river court
for its ferry institution, and Sunmere uses the old Sun Court for its cistern.
