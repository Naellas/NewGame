# Audio listening review, expanded v2

Open `index.html` directly in a browser; no server or dependencies. Compare the
walking previews and eight samples per surface. Preview volume is independent of
saved game settings. Flight previews loop; use Stop all to stop every preview.

In game: compare swords, shields, arrows, healing, wards and elemental attacks.
Try monster bites, giant impacts, skeletons and wolves. Release sounds should play
once; impacts should follow each collision at all combat speeds. Self buffs should
not produce projectile loops. Compare NPC crowds with the player alone; nearby
walkers should be faint, and stops/map changes must not produce phantom contacts.
The Footsteps slider still saves independently of SFX; Master controls both.

Automated routing, signal, timing and sample decoding pass. Subjective listening
and in-game mix acceptance for this revision remain pending.
