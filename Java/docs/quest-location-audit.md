# Whole-catalog quest location audit

Generated by `DialoguePlaceAudit` from the current runtime quest catalog. This checks every quest stage's location binding; it is a mechanical inventory, not a claim that every line has passed a human comprehension review.

Reviewed bindings: **134 quests / 355 stages**. Remaining generic indexed sites: **84 quests / 202 stages**.

All 26 main quests now have destinations in the [location library](../../Story%20premise/location-library.md). The rows below still use a numbered camp, field, graveyard, or similar site. An NPC may name a place in speech, but that does not guarantee its binding points there. Each row needs a named-place decision before directions are rewritten.

This inventory excludes local `story` anchors, explicit conversation contacts, and unlocated roaming hunts. Exclusion does not certify their prose: introduce unfamiliar people and customs using the [dialogue clarity rules](../../Story%20premise/dialogue-clarity-and-place-review.md).
