# City Asset Categories

City assets are grouped by usage while keeping the asset IDs unchanged. The Java asset catalog searches these folders recursively, so code should continue to reference assets by basename without folder prefixes.

- `buildings/<region>`: sun, river, north, freehold, fen, hearth, and shared; see [building guide](buildings/README.md).
- `overworld`: compact settlement icons used on the overworld map.
- `props/city`: city props, market pieces, alley plants, lamps, banners, and street clutter.
- `props/village`: placeable village props and village resource/work decorations.
- `structures`: bridges, walls, gates, and larger city construction pieces.
- `terrain`: city cobble, plaza, road, and snow road/cobble tiles.
