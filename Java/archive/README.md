# Archive

Storage for old or unused project files that should be kept out of the active game folders.

- [`pending-deletion/`](pending-deletion/README.md) - checksum-backed quarantine
  for deletion candidates, including the existing 437-file legacy cleanup bundle.

- `tools/` - retired helper scripts, generators, and experiments.
- `textures/` - unused or superseded texture files.
- `assets/` - old non-texture assets kept for reference.
- `misc/` - anything that does not fit the categories above.
