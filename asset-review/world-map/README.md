# World map review

The map now uses shoreline shading, terrain texture and forest, mountain, marsh,
dune and water symbols anchored to the actual world tiles. Roads use a light
ochre color. Terrain rendering remains cached by viewport and world revision.

Settlements, named sites and quests have independent label toggles; markers
remain available for hover. Grid is optional. One shared label layout reserves
marker space, prioritizes quests, avoids overlapping text and map edges, and
suppresses repeated nearby objective names. Quest cycles through active
destinations and highlights the selected destination. You also appears while
the player is inside a settlement.

Screenshots generated by `com.alderfall.game.WorldMapReviewTest`:

- `map-0.png`: overview with multiple accepted quests.
- `map-1.png`: zoomed map with all label categories.
- `map-2.png`: quest focus with settlement and site labels hidden.
- `map-3.png`: smaller window.

Validation: full Java compilation, WorldMapReviewTest (label collisions, bounds,
priority, quest focus and four actual UI renders), and RenderCacheTest passed.
Filters persist while the game is running; they are not written into saves.
