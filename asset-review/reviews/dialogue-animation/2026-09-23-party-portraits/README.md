# Party portraits and banter: D-drive verification

Actual GamePanel captures from the D-drive runtime build at 1280x720. Seraphine
and Aria use dialogue artwork, and banter attaches to the speaking portrait.
Automated checks cover artwork selection, speaker changes, compact paging,
reply hit targets/actions and cleanup. Captures were generated by the test;
no source artwork was edited or generated.

From `Java`, after building tests into `temp/dialogue-transfer/tests`:

```powershell
java '-Djava.awt.headless=true' -cp 'out;temp/dialogue-transfer/tests' com.alderfall.game.PartyPortraitHudTest
```

Scratch captures are overwritten under `Java/temp/party-portraits/`.
